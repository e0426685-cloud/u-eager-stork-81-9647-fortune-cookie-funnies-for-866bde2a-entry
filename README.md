A single fortune cookie message written for a software engineer — one line, 96 characters — for the make.fun bounty "Fortune Cookie Funnies for Engineers". The program validates the line (non-empty, single line, at most 120 characters) and writes it to `/output/entry.txt`.

## Entry

> You will inherit a codebase with no comments and a variable named temp_final_v2_REAL. Good luck.

## Run

```sh
python3 main.py
```
