## The fortune

> Your next deploy will go flawlessly, because this time you actually read the error message.

## How it works

`main.py` (Python 3.13, standard library only) writes the single fortune-cookie line above to `/output/entry.txt`, validating that it is one line of 1–120 characters.

Run it with:

```sh
python3 main.py
```
